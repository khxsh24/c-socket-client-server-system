TCP Client-Server Communication System

Overview

This project was developed in C as part of a networking and systems programming coursework. The objective was to design and implement a client-server communication system using TCP sockets, progressively extending functionality across multiple development stages.

The project demonstrates fundamental networking concepts, including socket creation, client-server communication, request processing, command handling, and service-based interactions.

Features

* TCP client-server communication
* Socket programming using C
* Message validation and processing
* Command-based request handling
* Date retrieval services
* Time retrieval services across multiple time zones
* Support for multiple client interactions
* Structured protocol design between client and server
* Error handling and input validation

Technologies Used

* C Programming Language
* POSIX Sockets API
* TCP/IP Networking
* Linux/Unix System Calls

Project Structure

client.c            Main client application
server1.c           Basic client-server communication
server2.c           Input validation and request handling
server3.c           Date service implementation
server4.c           Time zone service implementation
server5.c           Enhanced server functionality
firstclient.c       Additional client implementation
secondclient.c      Additional client implementation
